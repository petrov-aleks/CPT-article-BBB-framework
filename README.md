# BBB permeability decision framework for CNS PBPK modeling

This repository contains the MATLAB code, model inputs, clinical data, generated
simulation outputs, and numerical tables used in a manuscript on selecting and
evaluating blood–brain barrier (BBB) permeability inputs for central nervous
system physiologically based pharmacokinetic (CNS PBPK) modeling.

The manuscript is currently in the process of being submitted to a journal. A
link and full citation will be added after publication.

## What can be reproduced

The repository reproduces:

- Table 1 and Supplementary Tables S1–S5 as CSV files;
- main Figures 3–5;
- Supplementary Figure S1 and Figures S3–S15;
- compound-specific CNS PBPK simulations for ethanol, diazepam, paracetamol,
  ibuprofen, indomethacin, and mannitol;
- optimized BBB permeability–surface area products;
- the Tsinman-based PAMPA model fit and leave-one-out validation;
- summary exposure, GMR, and GMFE calculations;
- numerical agreement between the generated CSV tables and the TeX tables used
  in the manuscript.

Figures 1, 2, and 6 and Supplementary Figure S2 are conceptual or illustrative
figures. They are retained in the manuscript and are not part of the
computational reproduction workflow.

## Requirements

The workflow was developed and tested with:

- MATLAB R2025b;
- Optimization Toolbox;
- Statistics and Machine Learning Toolbox.

The repository includes the version of the
[Computational Physiology Toolbox](https://github.com/niklhart/compphysiol)
used for the analysis, together with the required CNS drug database, observable,
and plotting templates. A separate installation of `compphysiol` is therefore
not required.

Users may instead install `compphysiol` independently for their own work. The
reproduction workflow deliberately adds the bundled version to the MATLAB path
so that the analysis uses the same implementation as the manuscript. The
bundled toolbox retains its original BSD 2-Clause license.

## Quick start

1. Clone or download this repository.
2. Open MATLAB R2025b.
3. Set the repository root as the current MATLAB folder.
4. Run:

```matlab
run_reproduction
```

The master function adds all repository-local dependencies to the MATLAB path
for the current session and executes the table, simulation, analysis, figure,
and validation scripts in dependency order. Permanent changes to the user's
MATLAB path are not required.

At the end of a successful run, MATLAB reports:

```text
PASS: all displayed numerical values in Tables 1 and S1-S5 match their CSV sources.
Reproduction completed successfully.
```

## Population simulations for Figure S9

Population simulations are the most computationally expensive part of the
workflow. They are controlled by the following flag near the beginning of
`run_reproduction.m`:

```matlab
RUN_POPULATION_SIMULATIONS = false;
```

With the default value of `false`, the workflow uses the population simulations
already generated with this repository and stored in:

```text
results/simulations/supplementary_figures/figure_s9
```

Set the flag to `true` to regenerate them. This step takes approximately
10 minutes on the author's 2023 MacBook.

## Main workflow

`run_reproduction.m` performs the following steps:

1. Fits the Tsinman-based PAMPA model.
2. Generates Tables S5, S1, S2, S4, and Table 1.
3. Optimizes compound-specific BBB permeability and generates the six Table S3
   CSV files.
4. Generates main Figures 3–5.
5. Generates Supplementary Figure S1 and Figures S3–S8.
6. Generates Figure S9 from existing or newly regenerated population
   simulations.
7. Generates the surface-area simulations and Figure S10.
8. Calculates and plots the analyses for Figures S11 and S12.
9. Generates the IV/PO paracetamol simulations and Figure S13.
10. Generates the model comparison analyses and Figures S14 and S15.
11. Validates Tables 1 and S1–S5 against their manuscript TeX versions.

## Running individual components

The master workflow is recommended because it establishes the required paths
and respects all dependencies. To run individual scripts in a new MATLAB
session, first execute the following commands from the repository root:

```matlab
repoRoot = pwd;
addpath(genpath(fullfile(repoRoot,'code','dependencies','compphysiol','toolbox')))
addpath(genpath(fullfile(repoRoot,'code','dependencies','cns')))
addpath(fullfile(repoRoot,'code','utilities'))
```

## Model inputs and generated results

The simulation scripts read physiological, systemic PK, CNS, clinical dosing,
and permeability inputs from the CSV files under `data`. Derived and optimized
values are written under `results` and are subsequently used by the figure and
summary scripts.

Experimental permeability values are stored in their reported base units:

- normalized intrinsic permeability–surface area product, `PS0` in mL/s/g; or
- intrinsic permeability, `P0` in cm/s.

Translation to human `PS_BBB` uses a reference brain weight of 1450 g for
perfusion data and a human BBB surface area of 15 m² for permeability data. The
in silico permeability estimates are calculated from `logP` and molecular
weight using the equations documented in Table S5 and the manuscript.

## Table validation

The final validation can also be run separately after initializing the paths:

```matlab
addpath('code/utilities')
validate_manuscript_tables
```

The validator compares every displayed numerical value in the generated CSV
tables with the independently maintained TeX versions. It reports an error if
any value in Table 1 or Tables S1–S5 differs.
